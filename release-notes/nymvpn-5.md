# NymVPN :3

- Новый фирменный значок NymVPN :3 на Android и в ресурсах настольного приложения.
- Ссылка NymVPN выбирает профиль, автоматический маршрут, режим правил и VPN/TUN. Повторный импорт обновляет существующий профиль.
- Просроченные подписки обновляются через включённый VPN: проверка при подключении, смене сети и возвращении в приложение, а также раз в минуту, пока приложение работает.
- Интервал подписки NymVPN — один час. При сетевой ошибке сохранённая конфигурация остаётся доступной; повторная попытка через две минуты.
- Обновления без изменений не перезапускают подключение. Частные ссылки исключены из журналов импорта и загрузки.

Android требует системного разрешения VPN при первом подключении. Автообновление при полностью закрытом приложении в эту версию не входит. Работа на реальных телефонах и игровых соединениях требует проверки после установки.
