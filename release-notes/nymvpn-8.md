# NymVPN :3 — Windows и macOS

Версия для компьютеров с настройками, которые появились в Android .7.

- Главный экран под себя: перемещение, скрытие и возврат блоков, в том числе профиля Telegram. Наборы «Минимум», «Стандарт» и «Статистика».
- Профиль Telegram с уровнем, опытом и монетами; игра открывается в Telegram.
- Импорт ссылки NymVPN с автоматической настройкой и обновление подписки при работающем подключении.
- Отключение VPN по таймеру: 15, 30, 60, 120 или 240 минут.
- Отключение на ноутбуке при заряде 5, 10, 15 или 20%, только при работе от батареи.
- Имя и фиолетовая иконка NymVPN :3.

Настройки доступны через ползунки на главном экране или «Инструменты → Настроить NymVPN». Условия отключения изначально выключены. Они работают при сворачивании приложения; сон компьютера может задержать срабатывание. Само выключение экрана VPN не останавливает. После автоматического отключения используется обычное соединение.

## Скачать

- Windows x64: `.exe` — установщик, `.zip` — архив приложения.
- Mac с Apple Silicon (M1/M2/M3/M4 и новее): `macos-arm64.dmg`.
- Mac с Intel: `macos-x64.dmg`.

Это выпуск для компьютеров. Для Android актуальна [версия .7](https://github.com/dgsann/NymVPN-FlClash/releases/tag/v0.8.98-nymvpn.7).

Пакеты Windows не имеют подписи издателя, macOS — Apple Developer ID и нотарификации. При первом открытии система может запросить дополнительное подтверждение. Контрольные суммы файлов находятся в `SHA256SUMS`.

Автоматические проверки логики, интерфейса и сборок выполнены в CI. Работа на физическом ноутбуке с разрядом батареи и живым VPN-подключением отдельно не проверялась.
