NymVPN FlClash 0.8.98-nymvpn.3 — проверка передачи данных

Устанавливается поверх NymVPN FlClash nymvpn.2 с сохранением профилей.
После обновления приложения обновите прежнюю подписку и выберите **NymVPN-AutoTCP** в основной группе.
Рабочий **NymVPN-Telemost** остаётся отдельным пунктом.

AutoTCP проверяет загрузку всех 64 КБ и содержимое ответа через каждый кандидат.
При первом подключении проверяет Телемост и доступные прямые Reality-подключения AMS/Finland.
Рабочий путь сохраняется на пять минут; после этого проверяется при новом соединении.
При провале проверки выбирается другой проверенный путь. Проверки прекращаются при остановке VPN.
Диагностика пишет имя выбранного пути без адреса приватной проверки и ключей.

Это первая тестовая версия AutoTCP. Первое подключение может занять больше времени.
Переключение применяется к новым TCP-соединениям; уже открытый поток не переносится между путями.
UDP, звонки и игры через этот режим пока не поддерживаются.
Обновлённая подписка отклоняет неподдерживаемый UDP после основного правила,
чтобы ядро не отправляло его через неявный DIRECT. Явные прежние правила DIRECT сохраняются.
При недоступности самой точки проверки AutoTCP откажется выбирать путь; ручной NymVPN-Telemost остаётся доступен.
Режим выдаётся только тестовой учётной записи; подписки остальных пользователей не меняются.

Пакет: `com.follow.clash.nymvpn`, Android ARM64. Та же подпись, что в nymvpn.2.
